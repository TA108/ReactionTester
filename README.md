# 🎯 Reaction Tester

A simple web-based **Reaction Tester** game built using HTML, CSS, and JavaScript. Test your reflexes by clicking on randomly appearing shapes as quickly as possible. Your reaction time will be displayed after each successful click.

## 🧪 How It Works

* When the page loads, a shape will appear at a random position and size.
* As soon as you see the shape, click on it!
* Your reaction time (in seconds) is calculated and displayed.
* The shape reappears after each click — keep testing yourself!

## 🛠️ Technologies Used

* **HTML5** – Structure of the webpage.
* **CSS3** – Basic styling and layout.
* **JavaScript** – Core logic for randomness and timing.

## 🚀 Getting Started

To run this project locally:

1. Clone the repository:

   ```bash
   git clone https://github.com/your-username/reaction-tester.git
   ```
2. Navigate to the project directory:

   ```bash
   cd reaction-tester
   ```
3. Open the `index.html` file in your browser:

   ```bash
   open index.html  # macOS
   # or
   start index.html  # Windows
   ```

No additional setup is required.
